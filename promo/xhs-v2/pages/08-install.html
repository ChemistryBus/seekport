INSTALL

不用 pip install。
会 Python 就能装。

方式一：当 Skill 用 CLAUDE CODE
# 克隆 + 软链到 skills 目录 git clone https://github.com/ChemistryBus/seekport ~/seekport ln -s ~/seekport ~/.claude/skills/seekport # 填入你自己的 DeepSeek key export DEEPSEEK_API_KEY=sk-...
重启会话，就能在 Claude Code 里用。
方式二：当 MCP 用 任意 MCP
# 注册 stdio MCP server claude mcp add seekport -- \ python3 ~/seekport/mcp/seekport_mcp.py # 暴露两个工具 deepseek_search deepseek_fetch
以 Claude Code 为例；其他 harness 用 JSON 配置。
依赖只有 Python 3.9+ · 不用 pip · 不用 Node
建议 先跑通一次 search，再交给 Agent。
