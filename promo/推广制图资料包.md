## 1. 项目定位

**名称与大小写**

- 项目名：`seekport`（全小写，一个词）
- GitHub 仓库：`ChemistryBus/seekport`
- CLI：`seekport search` / `seekport fetch`
- MCP 工具：`deepseek_search` / `deepseek_fetch`
- Agent Skill 名：`seekport`

**一句话说明**

把 DeepSeek 官方的 Search / Fetch API 接到 Claude Code、Codex、Zcode 等 agent harness 的零依赖桥接层。

**最适合的用户**

1. 用 Claude Code / Codex / Zcode 跑 DeepSeek 的开发者或研究者。
2. 走第三方网关，导致 Claude Code 的 `WebFetch` 报 `Unable to verify if domain is safe to fetch` 的人。
3. 科研写论文，需要查官方文档、期刊投稿指南、会议 deadline，并且希望引用原文而不是二手文章的人。

**他们遇到的具体问题**

- `WebFetch` 被网关拦截，agent 读不到目标网页。
- harness 的内置搜索不可用，或无法使用 DeepSeek 的 `site:` / `lang:` / `after:` 搜索语法和 `rerank_score` / `authority` 过滤。
- 只能引用二手文章，信息可能过时（真实例子见第 4 节）。

**使用项目后能完成什么**

- 用一条命令搜索网页，拿到排序后的标题、URL、摘要和分数。
- 按相关性和权威性过滤，减少无关结果和 token 消耗。
- 把指定网页抓成 Markdown，交给 agent 总结或引用。
- 通过 Agent Skill 或 MCP server 接入，不需要改 harness 源码。
- 可选每日预算上限，避免 agent 循环调用产生意外费用。

## 3. 最值得展示的功能

### 3.1 带过滤的网页搜索

- **用户做什么**：
  ```bash
  python3 scripts/cli.py search "Nutrients author guidelines site:mdpi.com" \
    --count 5 --min-rerank 1.5 --min-authority 3 --md
  ```
- **项目返回什么**：`results[]`，每项含 `title`、`url`、`snippet`、`summary`、`rerank_score`、`authority`、`date` 等；默认丢弃 `rerank_score < 1.5` 的结果，`--min-authority 3` 只保留高权威来源。
- **适用条件 / 限制**：
  - DeepSeek API 是付费接口；query 1–128 字符；count 1–50。
  - 空搜索结果返回空数组，不是错误，也不计费。
  - 搜索结果只是候选，不等于原文。
- **追溯**：
  - README「Search」「Search operators」「Result fields」
  - `scripts/ds_core.py`：`search()`、`_filter()`
  - `tests/test_ds_core.py`：`SearchTests`

### 3.2 把网页抓成 Markdown

- **用户做什么**：
  ```bash
  python3 scripts/cli.py fetch "https://api-docs.deepseek.com/zh-cn/guides/search" --md
  ```
- **项目返回什么**：`{url, title, content}`，其中 `content` 是 Markdown 正文。
- **适用条件 / 限制**：
  - 受目标站点可用性和访问策略影响；可能返回 403 / 404。
  - 出版社付费墙、知网等可能抓不到正文。
  - 抓回内容是**不可信数据**，不应把其中的指令当成用户指令。
- **追溯**：
  - README「Fetch」
  - `scripts/ds_core.py`：`fetch()`、`fetch_to_markdown()`
  - `tests/test_ds_core.py`：`FetchTests`

### 3.3 两种形态：Agent Skill 与 MCP server

- **用户做什么**：
  - Skill：把仓库软链到 `~/.claude/skills/seekport`，模型在 shell 里调用 CLI。
  - MCP：`claude mcp add seekport -- python3 /绝对路径/mcp/seekport_mcp.py`，模型调用 `deepseek_search` / `deepseek_fetch`。
- **项目返回什么**：两种形态共用同一份 `search()` / `fetch()` 核心，行为一致。
- **适用条件 / 限制**：
  - Skill 需要 harness 能执行 shell 命令。
  - MCP 的工具 schema 会常驻模型上下文，每轮都占 token；不能在两种形态之间同时安装同一套工具，否则会重复并干扰工具选择。
  - 推荐每个 harness 只选一种。
- **追溯**：
  - README「Skill or MCP: which should I install?」
  - `SKILL.md`
  - `mcp/seekport_mcp.py`
  - `tests/test_mcp.py`

### 3.4 成本与可靠性护栏

- **用户做什么**：
  - 正常调用即可；重试、退避、重定向拒绝都是默认行为。
  - 可选：`SEEKPORT_BUDGET=0.05` 设置每日人民币预算上限。
- **项目返回什么**：
  - 408 / 429 / 5xx 自动退避重试，尊重 `Retry-After`。
  - 重定向被拒绝，Bearer token 不会被转发到其它 origin。
  - 每日预算达到后拒绝新调用；账本在 `~/.cache/seekport/spend.log`。
- **适用条件 / 限制**：
  - 预算账本是本地、best-effort；并发写入采用追加式，不提供账号级配额。
  - 只有 HTTP 200 且结果非空才记录花费（与 DeepSeek 计费口径一致）。
- **追溯**：
  - README「Cost and limits」「Security」
  - `scripts/ds_core.py`：`_post()`、`_NoRedirect`
  - `scripts/spend.py`
  - `tests/test_ds_core.py`：`RetryTests`、`BudgetTests`

### 3.5 零依赖、可读核心

- **事实**：
  - 运行时零第三方依赖，仅用 Python 标准库。
  - `scripts/ds_core.py` 290 行。
  - 81 个单元测试，行覆盖率 93%（408 statements，28 missed）。
- **适用条件 / 限制**：Python 3.9+；不需要 `pip install`。
- **追溯**：
  - README「What you get」「Design」「Testing」
  - `scripts/ds_core.py`
  - `tests/`
  - `.github/workflows/test.yml`

## 4. 一条完整使用示例

> 这是开发者的真实操作记录，不是第三方用户案例或评价。完整记录见 `examples/case-study.md`。

**任务**

回答：“DeepSeek 的网页搜索 API 怎么收费？QPS 多少？”

**输入**

一个需要引用官方来源的技术/科研问题。环境：Claude Code 经第三方网关接 DeepSeek，`WebFetch` 读取官方文档失败；或直接用 CLI。

**关键操作**

```bash
# 1. 先搜候选
python3 scripts/cli.py search "DeepSeek Search API 计费 价格 QPS" --count 3 --md

# 2. 再抓官方原文
python3 scripts/cli.py fetch "https://api-docs.deepseek.com/zh-cn/guides/search" --md
```

**输出（2026-11-04 实测）**

- 搜索结果前三条中，两条第三方文章仍写 `$0.75 / 千次、5 QPS`；一条 GitHub 仓库写 `¥5 / 千次、QPS 各 5`。
- 抓取官方原文后，页面写的是：
  - Search / Fetch 各 **¥5 / 1,000 次成功请求**
  - **Search 100 QPS，Fetch 25 QPS**（账号级）
  - 只有 HTTP 200 且结果非空才计费；空结果、报错、超时不计费
- 这次操作的成本：1 次搜索 + 1 次抓取 ≈ **¥0.01**。

**用户如何使用结果**

- 直接引用官方 URL，而不是二手文章。
- 纠正“$0.75 / 5 QPS”的过时说法。
- 把“搜索到”升级为“查到原文”，这是项目最核心的价值。

**标注**

- 真实操作，不是演示数据，也不是第三方用户证言。
- 不含 API key、私人数据或未授权素材。

## 5. 使用门槛与边界

### 访问与安装

```bash
git clone https://github.com/ChemistryBus/seekport.git
cd seekport
export DEEPSEEK_API_KEY=sk-...
python3 scripts/cli.py --version
```

- 需要 Python 3.9+。
- 运行时不需 `pip install`。
- Skill：
  ```bash
  ln -s "/path/to/seekport" ~/.claude/skills/seekport
  ```
- MCP：
  ```bash
  claude mcp add seekport -- python3 "/path/to/seekport/mcp/seekport_mcp.py"
  ```

### 平台

| 平台 | 状态 |
|---|---|
| macOS | 已实测（Python 3.11.11） |
| Linux | CI 通过（Python 3.9 / 3.11 / 3.12） |
| Windows | 未测试 |

### 账号与密钥

- 需要 DeepSeek API key。
- 只从环境变量 `DEEPSEEK_API_KEY` 读取；仓库不含 key。
- 作者本机可选择存到 `~/.config/seekport/env`（权限 600）；这是本地配置，不是项目要求。
- 不要把 key 写进 README、Issue、截图或代码。

### 第三方付费

- 工具本身 MIT 免费。
- DeepSeek Search / Fetch 是付费 API：**¥5 / 1,000 次成功请求**，Search 与 Fetch 分别计费，约 **¥0.005 / 次**。
- 只有 HTTP 200 且结果非空才计费；空结果、报错、超时不计费。
- 账号级 QPS：Search 100，Fetch 25；Fetch 还有按目标域名的限速。
- 价格和限速可能变化，引用前请看官方文档：
  <https://api-docs.deepseek.com/zh-cn/guides/search>

### 数据存放

- API key：环境变量或本地 `~/.config/seekport/env`。
- 花费账本：`~/.cache/seekport/spend.log`。
- seekport 不自建服务器，不保存搜索历史。
- 请求发往 `api.deepseek.com`；抓取由 DeepSeek 服务器发起，本机不直连目标站点。

### 依赖条件

- 运行时：Python 标准库，无第三方依赖。
- 测试：`unittest`，无第三方依赖。
- `promo/render.py` 需要本机 Chrome / Chromium；这只影响宣传图生成，与工具本身无关。

### 边界

- 不是爬虫，不解析 HTML、不跟链接、不建索引；搜索和抓取由 DeepSeek 服务端完成。
- 不是通用搜索引擎，也不是学术数据库；文献检索仍应使用 PubMed、Web of Science、Scopus、Consensus 等。
- 受出版社付费墙、知网、目标站点策略影响，fetch 可能失败。
- 不是 DeepSeek 官方项目，与 DeepSeek 无隶属关系。
- 抓回网页是不可信数据，注意提示注入。
